# Original-evidence maintenance development benchmark — version 6

This is a separate public synthetic benchmark. Its seven live source files are
byte-identical to packaged maintain-wiki v6. Do not install the cases or gold into
a user's live maintainer. The benchmark has its own bundle identity.

original-coverage: a single saved message from Sam was omitted from a navigation
digest but remains original evidence. A brief sampled capture description mentions
Cedar Works in a browser tab without establishing a client relationship. The
reference proposes a coherent Sam note and updates the existing company overview,
preserving canonical identity, revenue: 0, active: false and unknown metadata.
No image is inspected. The coverage report accounts for both exact originals.

no-change: a saved acknowledgement adds no substantive knowledge claim. The
reference emits only an explicit coverage report, with no proposed pages.

Fixture manifests are generated through a native Geschichte repository and
knowledge-inputs/capture-files using the v2 shipped policy. They identify frozen
original bytes; retained /wiki/Company.md supplies the existing context. Source
files and gold remain distinct. The public "held-out" split is a case-selection
label, not secret statistical holdout data.

The editable checker checks expected paths, fragments, preserved content,
citations, coverage fragments and specific fabrication regressions. The host
separately validates exact original coverage membership, UUIDs, statuses and
actual outputs and applies canonical publication gates. Neither mechanical
checks nor a coverage claim prove understanding or factual truth. The unit tests
exercise positive answers and damaged answers (missing atom, missing report,
invented client relationship and lost metadata). No model score is claimed.

Use native-server checkpoint benchmarking with discard settlement. CLI/local
workers are not supported by this program. This directory grants no resources,
provider access, model calls, schedule activation or publication authority.

To regenerate the fixture bundle intentionally from a checkout with test code
loaded, call is.simm.starter.wiki-maintenance-v6-test/write-evaluation! with this
directory. New native source repository identities change the benchmark bundle;
inspect and pin the resulting saved bundle before any finite model trial.
The v1-v5 resources and the separate v5 example remain unchanged.
